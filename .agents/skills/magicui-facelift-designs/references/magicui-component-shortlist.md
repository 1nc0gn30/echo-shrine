# Magic UI Component Shortlist

Use this shortlist for fast, cohesive facelift decisions.

## Components and fit
- `@magicui/text-animate`: hero/title animation with strong typography.
- `@magicui/blur-fade`: progressive reveal for sections.
- `@magicui/dot-pattern`: ambient background texture.
- `@magicui/marquee`: social-proof or capability strip.
- `@magicui/number-ticker`: metrics section.
- `@magicui/animated-gradient-text`: premium accent labels.
- `@magicui/magic-card`: interactive feature cards.
- `@magicui/shimmer-button`: high-emphasis CTA.

## Install pattern
- `npx shadcn@latest add @magicui/<component>`

## Usage pattern
- Import from `@/components/ui/<component-file>`.
- Keep one dominant animation style per section.
- Pair animated components with stable text blocks for readability.
